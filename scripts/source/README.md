# Source records

These JSON files are build inputs for `scripts/import-data.mjs`:

- `pose.json` — original Japanese records (POSE-DB-01, via the public Chinese mirror)
- `pose-zh.json` — Chinese-translated records (anhao/ai-pose-gallery-zh)

They are included so `npm run data` remains reproducible. They are **not**
covered by this project's MIT license; rights belong to the original author.
Do not redistribute these records as a standalone dataset.
